# AI Agent Documentation

Dokumentasi ini berisi panduan dan struktur untuk kebutuhan AI agent di proyek Flutter `hrm_app`.

## Tujuan

- Memberikan konteks fitur utama aplikasi mobile HRMS
- Menyimpan referensi kebutuhan bisnis dan fungsional
- Memudahkan AI agent dalam mengambil data dari markdown

## Struktur Direktori

- `docs/ai-agent/`
  - `README.md` - ringkasan dan tujuan dokumentasi AI agent
  - `business-requirements.md` - kebutuhan bisnis dan fungsional utama
  - `feature-mapping.md` - peta modul dan hubungan fitur
  - `data-models.md` - ringkasan model data penting (jika tersedia)
  - `api-contracts.md` - ringkasan endpoint API dan payload (jika tersedia)
  - `glossary.md` - definisi istilah kunci dari BRD

## Cara Pakai

1. Baca `business-requirements.md` untuk memahami tujuan dan ruang lingkup.
2. Gunakan `feature-mapping.md` untuk mengenali modul yang ada.
3. Tambahkan `data-models.md` atau `api-contracts.md` bila informasi backend atau alur data tersedia.
