# API Contracts

Tempat menuliskan ringkasan endpoint API dan payload yang penting untuk fitur mobile.

> Belum terisi. Tambahkan ketika struktur API backend tersedia.

## Contoh Struktur

- `POST /auth/login`
- `GET /attendance/today`
- `POST /attendance/clock`
- `GET /leave/balance`
- `POST /leave/request`
- `GET /approval/pending`
- `POST /approval/decision`
